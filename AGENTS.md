# Organization Visual History

This private repository is the archive and presentation layer for organization
visuals. It is not the source of truth for department composition, status or
ownership. Read `~/code/hq/AGENTS.md` and
`~/code/hq/governance/organization-architecture.md` before changing selected
maps or their interpretation.

Preserve original generated files. Add a new asset and gallery entry instead of
overwriting historical evidence. Every entry must state provenance, prompt or
prompt source, status and review conclusion.

Do not publish this repository or its contents publicly without an explicit
instruction from Danil.
